# ai4bharat

This repository appears to be a working copy for multilingual instruction-tuning and evaluation experiments built around the `IndicInstruct-main` codebase. It includes training scripts, evaluation utilities, DeepSpeed configs, and benchmark assets for Indian-language LLM workflows.

## What This Repository Contains

- Instruction-tuning and fine-tuning scripts
- Evaluation runners for multilingual benchmarks
- DeepSpeed and Beaker configuration files
- Dataset and benchmark assets for Indic-language experiments
- Gradio demos and utility scripts

## Main Folder

- `IndicInstruct-main/`: core training, evaluation, and deployment code

## Skills Demonstrated

- Multilingual LLM experimentation
- Instruction tuning workflows
- Distributed training configuration
- Benchmark evaluation for low-resource languages
- Model serving and demo setup

## Notes

This repository is organized as an experimentation and integration workspace around the `IndicInstruct-main` project rather than a polished standalone application.
